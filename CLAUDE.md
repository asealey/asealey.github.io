# CLAUDE.md — asealey.github.io

## What this is

Legacy personal blog (Jekyll, served via native GitHub Pages — no custom
CI/build pipeline). Superseded by [adamsealey-com](https://github.com/asealey/adamsealey-com)
as the current site; this repo is kept live for its existing published
posts and permalinks, not under active development.

## Standing rules

- **Feature branch + incremental commits, always.** Never commit directly
  to `master`.
- **Hold for human review before merging.** Report the branch and commit
  list back to Adam; never merge automatically.
- Site content/bio changes (About page, `_config.yml` description, etc.)
  are editorial, not engineering — flag staleness rather than editing it
  unprompted.
